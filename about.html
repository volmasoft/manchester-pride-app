About This Application

This is an unofficial application for Manchester Pride 2026 events. It aims to consolidate events from various venue websites into one convenient location to help attendees navigate the festival.

Features

  • Event Timeline: View all events organized by day and time
  • Venue Selection: Filter events by venue, e.g. perhaps you prefer to go to some venues or avoid others.
  • Ticket Status: We've tried to make it easier to know which events require a ticket or are free.
  • Event Details: Click on any event for more information
  • Accessible Version: A simpler list format for easier reading

Accessibility

We've tried to make this application accessible, and also provide an "Accessible Version" page which has no filters and is a plain listing.

Whilst this is a free effort, if you identify any accessibility issues please highlight them and we will try and fix them if we have time.

We have reviewed this application with:

  • WAVE Web Accessibility Evaluation Tool
  • WebYes
